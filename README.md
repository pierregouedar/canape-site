# Canapé

Page de présentation de Canapé, l'accueil console léger pour la ROG Ally.

La visite se parcourt au défilement ou avec les cinq boutons d'étape, accessibles au clavier. Les vues de l'Ally sont des maquettes animées.

Les états et mesures présentés renvoient aux essais documentés dans le dépôt Canapé ; les fonctions non essayées sur l'Ally restent signalées.
