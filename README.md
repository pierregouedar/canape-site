# Canapé

Page de présentation de Canapé, l'accueil console léger pour la ROG Ally.

Un seul fichier, `index.html`, sans dépendance ni étape de compilation. Publiée par GitHub Pages depuis la branche `main`.

Jeux, jaquettes et bannières : propriété de leurs éditeurs. Projet sans lien avec ASUS, Microsoft ou Valve.
